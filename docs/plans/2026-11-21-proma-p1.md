# Proma P1 分阶段实施计划

**目标：** 减少无效文件刷新和后台额度请求，补齐工作区记忆的编辑与恢复。

**架构：** 监听按应用存储根过滤；灵动岛保留原有交互，以展开代替后台轮询；记忆继续用 Markdown 和原子写入，保留最近一次保存前的版本。

**技术栈：** Electron、React、TypeScript、Bun。

1. `workspace-watcher-utils.ts`、`workspace-watcher.ts`：过滤 Proma 的会话持久化路径和原子写中间物。用 `bun test apps/electron/src/main/lib/workspace-watcher.test.ts` 验证内部写入不刷新、同名项目文件仍刷新。
2. `agent-island-service.ts`：限制停用后的后台处理；按展开触发额度刷新，不保留轮询计时器。验证节流、并发合并与跨生命周期的结果失效。
3. `agent-workspace-manager.ts`、`ipc.ts`、`preload/index.ts`、`WorkspaceMemoryWindowApp.tsx`：在现有读写权限范围内增加上一版本恢复和文件内定位；恢复必须先成为草稿，保存时检查原文冲突。验证快照范围和恢复策略。
4. 更新版本并运行阶段定向回归与差异检查，不构建、不打包、不提交。
